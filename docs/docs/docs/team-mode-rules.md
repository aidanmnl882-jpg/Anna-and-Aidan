# Ограничения и правила MVP (минимального продукта)

## Жесткие правила (согласовано с заказчиком)
* Максимум 4 игрока в команде.
* Код команды — 6 цифр (латиница), живет 10 минут.
* Любой игрок может отправить ответ, баллы общие.
* Чат, ссылки-приглашения, роли (капитан/игрок) — НЕ делаем.

## Схема экрана (текстовый прототип)
[Экран входа]
Кнопка 1: [ Создать команду ]
Кнопка 2: [ Присоединиться по коду ]
Поле ввода: [ _ _ _ _ _ _ ]
