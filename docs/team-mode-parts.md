# Декомпозиция: 3 минимальные части функции

## 1. Создание команды и код (Frontend + Backend)
* **Что делаем:** Экран «Создать/Присоединиться». API-эндпоинт `/api/teams/create`.
* **Зависимость:** Нужен новый тип данных `Team` в базе.

## 2. Общий счет (Backend + State)
* **Что делаем:** Поле `teamScore` в объекте квеста. При любом ответе проверяем `player.teamId` и плюсуем баллы туда.
* **Зависимость:** Нельзя делать без части 1 (иначе некуда писать счет).

## 3. Проверка состава (Backend)
* **Что делаем:** При входе по коду проверять, что в команде < 4 человек.
* **Зависимость:** Нужен быстрый запрос к БД по коду команды.
